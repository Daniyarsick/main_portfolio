Проекты

Четыре работы, по которым можно посмотреть код, документацию и реальные экраны.

Python · REST API

Books API на FastAPI

API для управления каталогом книг. Поддерживает CRUD, фильтрацию по автору и году, пагинацию и отдельный эндпоинт статистики.

  • Pydantic проверяет входные данные.
  • SQLAlchemy работает с базой SQLite.
  • API-key защищает операции создания, изменения и удаления.
  • OpenAPI-документация доступна через Swagger UI.

Технологии: FastAPI, Pydantic, SQLAlchemy, SQLite, OpenAPI

Kotlin · Android

Weather App

Android-приложение показывает текущую погоду и прогноз, полученные через OpenWeatherMap.

  • MVVM разделяет интерфейс и работу с данными.
  • Retrofit и Coroutines отвечают за сетевые запросы.
  • RecyclerView отображает прогноз, SharedPreferences хранит настройки.

Технологии: Kotlin, Android SDK, MVVM, Retrofit, Coroutines

Java · REST API

Task Management API

CRUD-сервис для управления задачами с хранением данных и базовой аутентификацией.

  • Код разделён на controller, service и repository.
  • Spring Data JPA работает с H2.
  • Spring Security ограничивает доступ и обрабатывает авторизацию.

Технологии: Java 17, Spring Boot, Spring Security, JPA, H2

Проектирование образовательного веб-ресурса до реализации. В репозитории описаны роли гостя, студента и администратора, а также путь от выбора курса до получения сертификата.
